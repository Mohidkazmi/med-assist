# Project Prompts Directory

This directory serves as a version-controlled registry of every prompt utilized during the development lifecycle of the **AI Medical Scribe Platform**.

---

## Guidelines

1. **Prompt Logging**: Save every significant prompt used to direct AI agents in this project inside this folder.
2. **Organized by Phase**: File naming conventions follow the active development phases (e.g. `phase-01-01-backend-skeleton.md`).
3. **No Overwrites**: Never overwrite or delete an old prompt. Storing the chronological progression of prompts is critical for tracking decisions and maintaining system history.
4. **File Structure**: Create exactly one markdown file per sub-phase.
5. **Documentation Integration**: This directory is an integral part of the project documentation and must be committed to version control.
